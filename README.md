Simple KPI Tracking Dashboard

Project Overview

This project focuses on analyzing Superstore sales data and creating a Simple KPI Tracking Dashboard using Python.

Objectives

- Calculate total revenue.
- Calculate total units sold.
- Find total orders.
- Calculate average order value.
- Identify the top-performing product.
- Visualize sales by category.
- Analyze monthly sales trends.

Technologies Used

- Python
- Google Colab
- Pandas
- Matplotlib

Dataset

Superstore Sales Dataset containing order details, customer information, product details, sales, quantity, discount, and profit.

Key Performance Indicators

KPI| Result
Total Revenue| $2,297,200.86
Total Units Sold| 37,873
Total Orders| 5,009
Average Order Value| $458.61
Top Product| Canon imageCLASS 2200 Advanced Copier

Dashboard Visualizations

1. Sales by Category – Bar Chart
2. Monthly Sales Trend – Line Chart
3. KPI Summary Dashboard

Tools

Google Colab was used to write and execute the Python code.

Conclusion

This project demonstrates how Python can be used to analyze sales data, calculate important business KPIs, and create visual dashboards for better understanding of business performance.
